# Sovereign typography

The interface uses **Cinzel** for royal titles and menu headings, and **Alegreya**
for readable descriptions, controls, numbers, and italic flavor text. Both are
served from this folder, with no third-party font requests. Georgia is the fallback.

Downloaded September 11, 2026 from the Google Fonts source repository:

- [Cinzel](https://github.com/google/fonts/tree/main/ofl/cinzel): `Cinzel[wght].ttf`,
  saved as `cinzel.ttf`. Copyright 2020 The Cinzel Project Authors.
- [Alegreya](https://github.com/google/fonts/tree/main/ofl/alegreya):
  `Alegreya[wght].ttf` and `Alegreya-Italic[wght].ttf`, saved as `alegreya.ttf`
  and `alegreya-italic.ttf`. Copyright 2011 The Alegreya Project Authors.

These are unmodified variable fonts licensed under the SIL Open Font License 1.1.
The complete notices are in `Cinzel-OFL.txt` and `Alegreya-OFL.txt`. Keep those notices
with redistributed fonts. The parchment, wood, trim, and crown are original CSS/SVG
in `style.css` and `index.html`.
